# Visual asset sources

The interface uses the hosted Google Fonts families below. The official specimen pages describe Noto Sans as a global font collection with Latin, Cyrillic, and Greek scripts and describe DM Sans as a variable geometric sans serif. They are used for the Azerbaijani question/UI text and headings respectively.

- Noto Sans: https://fonts.google.com/noto/specimen/Noto+Sans
- DM Sans: https://fonts.google.com/specimen/DM+Sans
